# Contributing

## Формат комітів

Conventional Commits: `тип: опис зміни`

- `feat` — новий функціонал
- `fix` — виправлення бага
- `docs` — документація
- `test` — тести
- `refactor` — зміна коду без зміни поведінки
- `chore` — рутина: конфіги, залежності, CI

Опис англійською, у наказовому способі, з малої літери, без крапки.
Перевірка: `This commit will <опис>` має звучати осмислено.

## Перед комітом

Усі чотири команди мають проходити:

    uv run ruff check .
    uv run ruff format .
    uv run mypy
    uv run pytest
